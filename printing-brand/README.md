# ThreadForge — Premium Apparel Manufacturing

A production-grade portfolio website for a premium bulk t-shirt printing and apparel manufacturing business.

## Tech Stack

- React 18
- TypeScript
- Vite
- TailwindCSS
- Framer Motion
- GSAP
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Structure

```
src/
├── components/
│   ├── ui/          # Reusable UI primitives
│   └── layout/      # Navbar, Footer
├── sections/        # Page sections
├── pages/           # Route pages
├── hooks/           # Custom hooks
└── utils/           # Utilities
```

## Deployment

Deploy `dist/` to any static host. See DEPLOYMENT.md for details.
