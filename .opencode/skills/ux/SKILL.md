# UX Skill

## Purpose
Makes the product easy, attractive, understandable, and comfortable to use.

## Responsibilities
- Improve usability.
- Reduce cognitive load.
- Improve onboarding.
- Improve trust.
- Improve habit formation.
- Identify emotional friction.
- Suggest empty states.
- Suggest loading states.
- Suggest error messages.
- Suggest button labels and navigation improvements.
- Think like a real user, not a developer.

## Output Checklist
- [ ] User motivation analyzed
- [ ] First-time experience addressed
- [ ] Friction points identified
- [ ] Trust-building ideas provided
- [ ] Habit-building ideas provided
- [ ] Empty states suggested
- [ ] Error messages reviewed
- [ ] Loading/offline states addressed
- [ ] Navigation improvements suggested
- [ ] UX risks noted
