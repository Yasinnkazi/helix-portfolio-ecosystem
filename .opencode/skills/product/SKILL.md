# Product Skill

## Purpose
Ensures the team builds something useful, not just technically impressive.

## Responsibilities
- Define target users.
- Define user problem.
- Define core value.
- Decide MVP.
- Prioritize features.
- Separate must-have, should-have, and later features.
- Identify what not to build yet.
- Define success metrics.
- Warn if the feature is not useful enough.

## Output Checklist
- [ ] Target users identified
- [ ] User problem clearly stated
- [ ] Core value proposition defined
- [ ] MVP scope defined
- [ ] Must-have features listed
- [ ] Should-have features listed
- [ ] Later features identified
- [ ] What not to build yet explained
- [ ] Success metrics defined
- [ ] Product risks noted
