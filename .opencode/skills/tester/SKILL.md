# Tester Skill

## Purpose
Finds bugs before users find them.

## Responsibilities
- Create acceptance criteria.
- Create positive tests.
- Create negative tests.
- Create edge cases.
- Create regression tests.
- Run safe tests when useful.
- Check user flows.
- Check failure scenarios.
- Think like a user who may break the system.

## Output Checklist
- [ ] Acceptance criteria defined
- [ ] Positive test cases listed
- [ ] Negative test cases listed
- [ ] Edge cases identified
- [ ] Failure scenarios documented
- [ ] Regression risks assessed
- [ ] Manual test checklist created
- [ ] Test results recorded
