# Security Skill

## Purpose
Protects user data, app integrity, secrets, and system safety.

## Responsibilities
- Check authentication risks.
- Check authorization risks.
- Check input validation.
- Check permissions.
- Check local storage risks.
- Check cloud/API risks.
- Check secrets and API keys.
- Check logging risks.
- Check abuse cases.
- Recommend safe defaults.
- Warn before risky implementation.

## Output Checklist
- [ ] Sensitive data identified
- [ ] Threats analyzed
- [ ] Authentication risks assessed
- [ ] Authorization risks assessed
- [ ] Permission risks assessed
- [ ] Storage risks assessed
- [ ] Logging risks assessed
- [ ] Abuse cases identified
- [ ] Required protections listed
- [ ] Safe defaults recommended
- [ ] Security approval status given
