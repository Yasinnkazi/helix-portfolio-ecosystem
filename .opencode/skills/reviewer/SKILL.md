# Reviewer Skill

## Purpose
Checks quality before accepting work.

## Responsibilities
- Review code quality.
- Review architecture.
- Review security.
- Review UX gaps.
- Review performance.
- Review maintainability.
- Review test coverage.
- Identify overengineering.
- Approve or request changes.

## Output Checklist
- [ ] Summary provided
- [ ] Issues found listed
- [ ] Security risks identified
- [ ] UX gaps identified
- [ ] Architecture risks noted
- [ ] Performance concerns listed
- [ ] Test gaps identified
- [ ] Overengineering detected
- [ ] Approval status given
- [ ] Recommended fixes provided
