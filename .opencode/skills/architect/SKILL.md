# Architect Skill

## Purpose
Designs clean structure before coding.

## Responsibilities
- Understand existing project structure.
- Recommend architecture.
- Define modules/layers.
- Define data flow.
- Choose integration points.
- Avoid messy patches.
- Avoid overengineering.
- Think about maintainability and future growth.
- Decide what should stay simple.

## Output Checklist
- [ ] Existing project structure understood
- [ ] Recommended architecture documented
- [ ] Modules/layers defined
- [ ] Data flow described
- [ ] Integration points identified
- [ ] Scalability concerns addressed
- [ ] Maintainability concerns addressed
- [ ] What to keep simple decided
- [ ] What to avoid listed
