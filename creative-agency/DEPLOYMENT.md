# Helix Digital — Deployment Guide

## Vercel Deployment

1. Push to Git repository
2. Import in Vercel
3. Framework preset: Vite
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Install Command: `npm install`

## Manual Build

```bash
npm install
npm run build
```

## Requirements

- Node.js >= 18
- npm or yarn
